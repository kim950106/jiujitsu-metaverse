# 주짓수 메타버스

띠를 매고 도장과 대회장을 걸어 다니는 3D 웹 놀이터입니다. 설치 없이 휴대폰 브라우저에서 열리고, 같은 주소로 들어온 사람끼리 만납니다.

- 접속 주소: https://kim950106.github.io/jiujitsu-metaverse/
- 개인 취미로 만든 **비공식 팬 프로젝트**입니다. 퍼스트짐, IBJJF, 경기장 운영 측과 관계가 없고 상업적으로 쓰지 않습니다. 단체 로고는 들어 있지 않습니다(아래 "로고 넣기" 참고).

## 들어 있는 것

- 첫 화면에서 장소(도장 / 대회장), 띠와 그랄, 도복 색, 이름을 고르고 입장
- 왼쪽 스틱으로 이동. 오른쪽에는 큰 버튼과 그 둘레의 버튼: 스파링, 말, 동작(브릿지·엉덩이 걷기·스탠드업·정좌·인사·구르기·새우빼기), 앞구르기, 뒷구르기, 새우빼기, 정좌. 키보드는 방향키 이동, Shift 달리기, F 스파링, Q 브릿지, W 엉덩이 걷기, E 스탠드업, R 정좌, A 인사, S 앞구르기, D 뒷구르기, T 새우빼기, Z X C V 말
- 휴대폰에서는 입장하면 가로 화면이 됩니다. 회전 잠금이 켜져 있어도 화면이 옆으로 놓이므로 휴대폰을 돌려 잡으면 됩니다. 메뉴에서 세로로 바꾸거나 반대쪽으로 뒤집을 수 있습니다
- 화면은 휴대폰 화면에 꼭 맞게 고정됩니다. 두 손가락으로 벌려도 화면도 시점도 확대되지 않고, 가까이·멀리는 오른쪽 위 ＋ － 버튼으로만 합니다(누르고 있으면 계속)
- 카카오톡·라인·인스타그램 같은 앱 안에서 링크를 열면 휴대폰의 기본 브라우저로 넘어갑니다(아이폰의 다른 앱은 ‘Safari로 열기’ 안내)
- **스파링**: 매트 위에서 상대에게 붙어 스파링 버튼을 누릅니다. 도장 식구(NPC)는 바로 시작하고, 사람은 수락해야 시작합니다. 인사하고 손바닥을 마주친 뒤 한 판마다 가위바위보를 해서, 이긴 쪽이 그 판을 가져가며 포지션을 잡습니다. 서 있을 때 이기면 테이크다운(상대의 가드 안), 위에서 이기면 가드 패스 → 마운트 → 백 테이크, 밑에 깔려서 이기면 스윕으로 뒤집습니다. 승부를 가르는 마지막 판을 이긴 쪽만 미리 고른 기술(앵클락, 암바, 길로틴, 오모플라타, 백초크, 트라이앵글, 기무라)로 마무리하고, 상대가 탭하면 끝납니다
- **관장님**: 관장님과의 스파링은 내 띠에 따라 이길 확률이 정해집니다. 흰 띠 0%, 파란 띠 1%, 보라 띠 5%, 갈색 띠 10%, 검은 띠 40%
- **판 수**: 흰 띠 5판 3선승, 파란 띠 6판 4선승, 보라 띠 7판 4선승, 갈색 띠 8판 5선승, 검은 띠 10판 6선승. 띠가 다르면 낮은 띠의 규칙. 판을 다 채우고 동점이면 서브미션 없이 무승부
- **연승**: 스파링을 이어서 이기면 이름 옆에 "n연승"이 붙습니다. 이름은 머리 위에 작게 떠 있습니다
- **검은 띠**: 김상인, 양동건, 서현찬 세 이름만 고를 수 있습니다(추가는 개발자에게 요청). 검은 띠의 줄은 단수로 0~6단
- **선수카드**: 대회장에 처음 들어갈 때 이름·벨트·나이를 적으면 캐릭터 사진이 들어간 카드가 발급됩니다. 나이는 그 기기에만 남습니다
- **말과 샤카**: "안녕하세요." / "한판 하실래요?" / "내일봐요" 말풍선, 샤카 🤙
- **엉덩이걷기 경주**: 도장 매트의 6 m, 레인 3개. 출발 신호 뒤 큰 버튼을 누를 때마다 엉덩이걷기 한 걸음, 연타할수록 빠릅니다. 출발선 곁에 있던 사람은 옆 레인에서 함께 달리고, 서로의 기록과 등수가 나옵니다
- **단체 사진**: 셋을 센 뒤 지금 화면을 버튼 없이 사진으로 만들어 저장하거나 보냅니다
- **게시판**: 손가락으로 그려서 남기는 한마디. 남긴 날짜와 이름, 띠, 그랄이 함께 적힙니다
- 도장(6층): 관장님께 물어보기, 시간표, 띠 안내판, 라운드 타이머, 폴딩도어 밖 6층 테라스 잔디마당과 야외 매트, 둘레의 아파트 단지. 실제 시각에 따라 낮, 노을, 밤으로 바뀝니다
- 대회장: 관중석, 빈 매트 2면과 점수판, 지도자석(검은 띠 1명), 몸 푸는 곳, 시상대
- 홈 화면에 추가하면 주소창 없이 가로 화면으로 열립니다(메뉴 → 앱처럼 열기)

## 여러 명이 만나는 방식

서버를 따로 두지 않고, 누구나 쓸 수 있는 공개 MQTT 중계 서버 세 곳(broker.emqx.io, broker.hivemq.com, test.mosquitto.org)에 동시에 접속합니다. 한 곳만 살아 있어도 만납니다.

- 주고받는 것은 이름, 띠, 도복 색, 위치, 동작, 고른 말의 번호처럼 화면에 보이는 것과 게시판의 그림뿐입니다. 직접 쓴 글자나 연락처는 보내지 않습니다
- 게시판 그림은 같은 중계 서버에 "마지막 메시지 보관" 기능으로 올려 두고, 한번 본 그림은 각자의 브라우저에도 보관했다가 서버에 없으면 다시 올립니다. 무료 공개 서버라서 오래 남는다는 보장은 없습니다
- 공개 서버라서 이 내용은 다른 사람도 볼 수 있고, 서비스가 느려지거나 멈출 수 있습니다
- 주소 끝에 `?r=코드`를 붙이면 그 코드를 쓰는 사람끼리만 모입니다(비밀번호는 아닙니다)

## 로고 넣기

이 저장소에는 어느 단체의 로고도 들어 있지 않습니다. 맵 안의 배너 자리는 두 가지 방법으로 채웁니다.

- **모든 방문자에게 보이게**: 저장소 맨 위에 있는 `logo-gym.png`(도장 배너, 바깥 간판, 도복 등판)와 `logo-event.png`(대회장 배너, 전광판, 시상대)를 같은 이름의 로고 이미지로 바꿔 올립니다. 처음 들어 있는 것은 1픽셀짜리 빈 이미지이고, 빈 이미지는 "로고 없음"으로 봅니다
- **내 화면에서만**: 게임 안 메뉴 → "로고 이미지 넣기"에서 파일을 고릅니다. 그 브라우저에만 저장되고, 위의 파일보다 먼저 쓰입니다

로고는 그 주인의 것입니다. 공개된 주소에 올리기 전에 도장이나 단체의 허락을 받아 주세요.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 실제로 서비스되는 한 파일짜리 페이지. `sh build.sh`가 만들어 내므로 직접 고치지 않습니다 |
| `src/page.html` | 화면 구조와 스타일 |
| `src/*.js` | 게임 코드. `relay.js`가 중계 서버 연결, `net.js`가 다른 사람 표시, `tech.js`·`character.js`가 기술 동작, `spar.js`가 스파링, `card.js`가 선수카드, `race.js`가 경주, `guest.js`·`guestui.js`가 게시판, `schedule.js`가 시간표, `yard.js`가 테라스, `sky.js`가 낮과 밤, `stage.js`가 가로 화면 |
| `logo-gym.png`, `logo-event.png` | 로고 자리에 쓰이는 이미지. 다시 올릴 때 덮어쓰지 않도록 주의 |
| `manifest.json`, `icon-*.png`, `apple-touch-icon.png` | 홈 화면에 추가할 때 쓰이는 이름과 아이콘. 아이콘은 `python3 tools/icons.py`가 그립니다(띠 모양의 자체 그림) |
| `og.png` | 메신저에 주소를 보냈을 때 뜨는 미리보기 그림. `node tools/og.mjs`가 게임 화면으로 만듭니다 |
| `test/` | 자동 테스트 |
| `build.sh`, `build-web.mjs` | 빌드 스크립트 |

## 고쳐서 다시 올리기

```sh
npm install
sh build.sh         # index.html 을 다시 만듭니다
npm test            # 게임 규칙과 중계 연결 테스트
git add -A && git commit -m "변경 내용" && git push
```

`main` 브랜치에 올리면 GitHub Pages가 1~2분 안에 새 버전을 내보냅니다.

`npm run test:page`는 브라우저를 띄워 가로 화면과 터치, 두 손가락 확대 막기와 ＋ － 버튼, 버튼 배치와 키, 스파링(포지션과 마무리)과 경주와 단체 사진, 게시판, 테라스의 시점, 로고 자리, 홈 화면용 파일, 카카오톡 같은 앱 안 브라우저에서 기본 브라우저로 넘기기, 두 사람이 실제로 만나 스파링 신청·수락과 경주를 주고받는지를 확인합니다(Chrome 필요, 25분쯤 걸립니다). `node test/techshot.mjs`는 기술 동작을 여러 각도에서 찍어 `shots/`에 모아 줍니다.
